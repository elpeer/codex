# Elevate WhatsApp Button (WordPress Plugin)

תוסף וורדפרס המאפשר להציג כפתור וואטסאפ צף עם שליטה נפרדת לדסקטופ ומובייל.

## יכולות
- הגדרת מספר הטלפון.
- הגדרת הודעת פתיחה אוטומטית.
- הגדרת טקסט הכפתור.
- מיקום בדסקטופ: שמאל למטה או ימין למטה.
- מובייל: אייקון בלבד או כפתור מלא עם טקסט.
- מיקום במובייל: שמאל/מרכז/ימין למטה.

יוצר התבנית: **Elevate Digital Studio**.
